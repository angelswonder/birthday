
# Birthday Garden

A modern Next.js birthday website with a beautiful floral theme, glowing memory cards, virtual cake with microphone blow detection, and heartfelt love letter.

## Features

- **Memory Lane**: Interactive cards with images/videos, animated stories, and slideshow mode with floral prev/next buttons
- **Virtual Cake**: Blow out candles using your microphone
- **Love Letter**: Sweet birthday wishes with Spotify gift link
- **Beautiful Theme**: Green, sky blue, baby pink, and soft pastel colors with fairies and bunnies
- **Background Music**: Page-specific tracks that play automatically

## Setup

1. Install dependencies: `npm install`
2. Run the development server: `npm run dev`
3. Open [http://localhost:3000](http://localhost:3000)

## How to Use

- Click "Enter the Birthday Garden" to start
- Navigate between Memory Lane, Cake Wishes, and Love Letter
- In Memory Lane, click cards to view stories
- Start slideshow for automatic cycling with floral navigation buttons
- On Cake page, enable microphone and blow to extinguish candles
- Enjoy the background music that changes per page

## Technologies

- Next.js 14 with TypeScript
- Tailwind CSS for styling
- Web Audio API for microphone interaction
